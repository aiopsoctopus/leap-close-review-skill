# A Few Other Ideas

The close-review skill is built around what I read as the most urgent thing in this role: bringing the full controller function in-house and owning it independently, start to finish. Everything below is secondary to that — a few other places I'd look, based on things that came up in our conversations, not a wishlist.

## Finance

**RCM denial/aging triage.** A natural extension of the close-review skill — given claim status data, categorize denial reasons and draft a recommended next action (resubmit, appeal, write off) for human sign-off. Aimed at scaling RCM without adding headcount.

**QBR / account-performance reporting.** Pull banking and finance data per employer account and draft the savings summary each client sees in their QBR — generated instead of manually assembled each quarter.

**Vendor bill coding assistant.** Suggest GL coding for new bills based on historical patterns, for human approval — keeps AP moving as bill volume grows with headcount.

**Accrual/JE drafting assist.** Given a described event (an unbilled vendor cost, a bonus accrual), draft a proposed journal entry — account codes, debit/credit, plain-English rationale — for review, never auto-posted.

## People Ops

**Onboarding workflow builder.** Generates the full pre-start checklist and week-1 schedule from a new hire's role and start date, and flags what's missing from the current process as it builds — aimed at moving past a compliance-only baseline.

**Headcount plan / fully-loaded cost model.** I've built this exact tool before — ingests payroll and financial data, outputs a board-ready cost model tied to real headcount plans, not a wish list.

**PEO-to-in-house payroll readiness model.** Models the cost and complexity tradeoff of a PEO transition against headcount and compliance thresholds, so that conversation starts with real numbers.

## Cross-functional

**AI enablement map.** Maps which processes across the org are manual versus automated, prioritizes the highest-leverage next targets, and tracks ownership — so nothing falls into a gap. If I had to pick one thing to own first beyond the close, it's this.

**Decision log / initiative tracker.** Extracts decisions, owners, and open items from meeting notes and flags anything that's gone stale or unowned.

**Meeting pre-read assistant.** Drafts the one-page agenda and pre-read ahead of recurring meetings, so the meeting itself stays focused on decisions rather than status updates.

---

The thread connecting all of these is the same one behind the close-review skill: compress the mechanical, repeatable work so time goes to the decisions that actually need a person.
